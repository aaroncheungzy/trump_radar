核心功能

新闻监控

  • 自动抓取指定 RSS 源新文章
  • 智能过滤短内容和重复文章
  • 记录处理历史，避免重复分析

翻译与分析

  • 豆包 + DeepSeek 双模型翻译
  • 结合金融数据生成经济影响分析
  • 专业投资者建议输出

金融数据

  • 实时获取纳斯达克指数
  • 加密货币（BTC/ETH/SOL/XRP）价格
  • 24小时涨跌幅统计

自动推送

  • HTML 格式报告邮件
  • 支持多收件人配置
  • 定时/手动触发灵活切换

快速开始

1. 环境准备

Python 3.8+ 环境，安装依赖：

pip install -r requirements.txt

2. 配置文件

修改 config.json 配置关键参数：

  • 邮件配置（发件人、收件人、授权码）
  • AI 模型 API 密钥（豆包/DeepSeek）
  • 监控的金融资产（可自定义）

3. 运行方式

本地运行：

python news_monitor.py

GitHub Actions 运行：

  • 配置仓库 Secrets（邮件/API 密钥）
  • 手动触发或定时自动运行

配置说明

参数类别 关键参数 说明
邮件配置 email.from
email.password

常见问题

Q1: 依赖安装失败？

A: 确保 pip 版本最新，GitHub Actions 环境会自动安装所有依赖，本地运行可手动安装缺失的库（如 lxml）。

Q2: 邮件发送失败？

A: 检查 SMTP 配置，QQ/163 邮箱需使用授权码而非登录密码，确保开启 SMTP 服务。

Q3: 无法获取新闻内容？

A: 检查目标 RSS 源是否可访问，需要代理时配置 HTTP_PROXY/HTTPS_PROXY 环境变量。
